# Capital Clara

Prototipo visual de una landing page informativa para captar consultas sobre oportunidades de inversión.

## Ver el prototipo

Abrí `index.html` directamente en tu navegador o levantá un servidor local:

```bash
python -m http.server 4173
```

Luego visitá `http://localhost:4173`.

## Configurar antes de publicar

1. En `script.js`, reemplazá `WHATSAPP_NUMBER` por el número internacional oficial, por ejemplo `5491100000000`.
2. Reemplazá `contacto@capitalclara.com` por el email real en `index.html` y `script.js`.
3. Reemplazá el nombre provisional **Capital Clara** y los textos de los planes.
4. Completá los datos legales, privacidad y la advertencia de riesgo con una revisión profesional adecuada.
5. Verificá la normativa aplicable en Argentina antes de publicar o ofrecer productos financieros.

Los botones de WhatsApp funcionan como enlaces a la sección de contacto mientras el número esté pendiente. El formulario prepara un mensaje y, si no hay número configurado, intenta abrir el cliente de correo.
